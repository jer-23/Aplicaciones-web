# Guía V.1 - Proyecto de Gestión de Elementos de Taller/Laboratorio

## Objetivo General
Desarrollar una aplicación web interactiva para gestionar elementos de taller o laboratorio.

## Reglas y Consideraciones
1. El usuario es principiante. Explicar brevemente qué se hace y cómo probarlo.
2. Trabajar exclusivamente dentro de la carpeta del proyecto.
3. Seguir el siguiente orden estricto de desarrollo:
   - Estructura inicial (HTML, CSS, JS básicos)
   - Interfaz responsive
   - Interactividad
   - Conexión con JSONBin (Base de datos / Almacenamiento)
   - Pruebas en PC y celular
   - GitHub (Control de versiones)
   - Despliegue en Vercel (Publicación web)
4. Desarrollar sin frameworks ni dependencias innecesarias por ahora (Vanilla JS/CSS/HTML).
5. No conectar todavía JSONBin, GitHub ni Vercel hasta llegar a sus respectivas etapas. Si se requiere usar alguna de estas herramientas (o cualquier otra), se debe avisar primero.
6. Antes de crear archivos, revisar la carpeta e indicar qué se va a crear. No borrar ni sobrescribir sin consultar.
7. Al terminar cada etapa, indicar qué archivos se crearon, cómo ejecutar la aplicación y cómo comprobar que funciona.
8. No avanzar a la siguiente etapa sin la confirmación del usuario.
